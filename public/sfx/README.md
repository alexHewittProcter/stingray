# Sound assets

## `launch-stations.wav`

The "Launch Stations" PA drum signal the base sounds when Troy is on foot in the control room (the `ALERT`).

An **original modelled recreation**, generated by [`tools/launch-stations.py`](../../tools/launch-stations.py) —
deterministic, from code: modelled marching snare and tenor drum voices on an original pattern (180 bpm, three bars,
4.000 s), run through a modelled 1963 PA chain (band-limiting, tape saturation, compression, a whisper of hiss).
Nothing in it is sampled from, transcribed from, or derived from episode audio; the brief it was built against is
[`docs/briefs/launch-stations-prompt.md`](../../docs/briefs/launch-stations-prompt.md), whose pattern grid is a
character sketch, not a transcription.

Mono, 48 kHz, 16-bit, peak −1 dBFS. Regenerate with `python3 tools/launch-stations.py`; see `docs/witnessing.md`
(*The Launch Stations signal*).
